About TechGuide

TechGuide is an offline, rule-based technology help desk. It matches questions to a fixed set of review-ready guides for teacher review; it does not use a language model or send messages to any server.

Messages exist only in this page's memory and are cleared when you start a new chat or close the page. Avoid entering personal information. No account, analytics, cookies or persistent chat logs.

Only use devices and resources assigned by your teacher. Stop when instructions are blocked, equipment is damaged, or a fix requires changing permissions or administrator settings.

Version 1.1 is ready for a classroom pilot; school staff should review instructions for local device versions and rules.
